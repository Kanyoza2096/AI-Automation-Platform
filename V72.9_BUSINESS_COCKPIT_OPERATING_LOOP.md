# V72.9 — Business Cockpit Operating Loop & Human Decision Workspace

V72.9 composes durable truth, intelligence, recommendations, recorded decisions,
and learning into a single business operating surface.

## Safety

The service is read-only. A work item is not a command. A command intent is not
authority. Human takeover/resume returns to the existing governance boundary.
No provider, Action Kernel, durable outbox, or policy mutation is invoked.

## Canonical loop

TRUTH → INTELLIGENCE → RECOMMENDATION → DECISION → GOVERNED EXECUTION → RESULT → OUTCOME → LEARNING

## Next integration

KCPG should expose this model through the existing Business Command Center route
without changing the existing System Control Center route `/api/v1/command-center/situation`.
