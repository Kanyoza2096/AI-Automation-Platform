# V71.11 — Governed AI Workforce Observability & Control Plane

## Purpose
Provide an operator-facing read/control plane for autonomous workforce runs.

## Boundary
V71.11 does **not** execute providers, grant permissions, approve actions, or
replace the Action Kernel, durable outbox, reconciliation system, or V71.9
admission facade.

## Controls
- Pause: prevents further autonomous progress. A running run is fenced and marked reconciliation-required.
- Fence: explicitly marks a run uncertain; it is never a retry instruction.
- Resume: only returns a reconciled paused run to `READY`; subsequent execution must re-enter V71.9 governance.
- Cancel: terminal cancellation; no provider call is performed.

## Evidence
Operator control events are fingerprinted and stored in `agent_workforce_events`.
Tampering is rejected when events are read.

## Safety invariant
`resume != execute`. The control plane only changes durable run state. It cannot
turn advisory information, evaluation, budget, memory, or operator controls into
execution authority.
