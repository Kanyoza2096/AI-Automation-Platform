# V71.3 — Governed AI Workforce: Agent Memory

## Status
IMPLEMENTED — OFFLINE VERIFIED

V71.3 introduces a tenant-scoped memory plane for AI workers. Memory provides context and evidence; it never grants authority, permission, approval, provider access, or execution rights.

## Controls
- Active-agent requirement for writes and recall
- Tenant/workspace isolation
- Deterministic memory fingerprints
- Tamper detection
- Explicit provenance/source
- Confidence bounded to 0..1
- Expiry and revocation
- Supersession metadata
- Conflict detection; conflicting active memories are excluded by default
- Advisory-only recall contract
- No action/authority fields in usable context

## Architectural invariant
Identity answers **who**. Permissions answer **what capability may be requested**. Memory answers **what context/evidence the worker can recall**. Existing policy, risk, Council/human approval, Action Kernel, outbox and execution controls remain authoritative.
