# V67.11 — External Provider Certification Contract

## Objective

Turn V67.10's controlled side-effect chaos model into a formal, fail-closed
provider certification boundary. KDO must not treat an arbitrary external API
as autonomous-safe merely because it accepts an idempotency key.

## Required provider evidence

1. **Atomic, key-scoped idempotency** — a replay cannot create a second remote object.
2. **Remote reconciliation** — KDO can discover committed state after a lost response.
3. **Sandbox isolation** — certification cannot reach production tenants/resources.
4. **Controlled termination** — worker termination after provider commit is testable.
5. **Correlation** — submit/reconcile operations carry the KDO correlation identity.

## Governance boundary

This release certifies the adapter contract only. It does not authorize a
provider, execute a business action, or claim live third-party certification.
A provider-specific adapter must independently pass this gate before a live
V67/V68 certification run can use it.

## Result

The built-in synthetic provider passes the contract. Arbitrary non-sandbox
adapters fail closed.
