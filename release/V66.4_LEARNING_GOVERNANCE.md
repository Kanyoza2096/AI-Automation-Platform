# V66.4 — Learning Governance + Promotion

V66.4 separates **learned evidence** from **trusted reusable knowledge**.

## Rules

- Learning signals remain descriptive evidence.
- Promotion requires at least 3 consistent observations, average confidence >= 0.75, and >= 0.67 directional consistency.
- Conflicting positive/negative evidence is marked `contradicted` and is never promoted.
- Evidence older than the configured freshness window is `stale`.
- Uncertain and insufficient-evidence signals are excluded from promotion.
- Confidence can decay without modifying the source learning record.
- `authority` is always `none`.
- V66.4 does not modify policy, approvals, Action Kernel contracts, or execution permissions.

## Architecture

`Outcome Observation -> Attribution -> Measurement -> Learning Signal -> Learning Governance -> Reusable Knowledge`

Reusable knowledge remains advisory input for future planning. Authorization remains owned by the decision/policy/action execution planes.
