# V71.2 — Governed AI Workforce: Capability Permissions

V71.2 adds the permission plane between agent identity and existing governance.

## Invariant
An agent may request a capability only when:
1. the agent exists in the same workspace and its identity is intact;
2. the agent is ACTIVE;
3. the capability was declared by that identity;
4. an explicit permission allows the requested scope; and
5. no matching explicit DENY overrides the allow.

Permission does **not** approve an action, bypass policy/Council/human review,
grant provider access, or call the Action Kernel. Consequential execution remains
on the canonical KDO governance/execution path.
