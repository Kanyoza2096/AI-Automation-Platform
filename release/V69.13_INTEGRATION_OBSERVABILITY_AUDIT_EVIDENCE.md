# V69.13 — Integration Observability & Audit Evidence Plane

## Purpose
Every material integration control-plane observation or decision can now be represented as tenant-scoped, append-only evidence without storing credentials or granting authority.

## Evidence contract
- Tenant, connection and connector identity are mandatory.
- Evidence is descriptive only: `authority_granted=false`, `execution_effect=none`.
- Provider payloads are never persisted; only a SHA-256 fingerprint is retained.
- Sensitive metadata keys are redacted.
- Per-connection evidence is hash-chained with `previous_hash` and `evidence_hash`.
- Duplicate IDs, chain breaks and hash tampering fail closed in the reference store.
- Production persistence is expected to use the supplied SQL table with RLS and a trusted server-side adapter.

## Intended event coverage
`lifecycle_transition`, `certification`, `activation`, `health_observation`, `drift`, `recertification`, `ingress_accept`, `ingress_reject`, `runtime_allow`, `runtime_block`, `execution_observed`, `reconciliation`, `revocation`, `recovery`.

## Boundary
V69.13 does not turn evidence into authority. Runtime authorization, DecisionGate/Action Kernel, durable outbox and provider reconciliation remain authoritative for side effects.
