# V70.4 — Canonical Runtime & Intelligence Reconciliation

## Purpose

V70.4 is a convergence gate. It does **not** introduce another workflow engine,
Action Kernel, outbox, connector executor, event bus, or recovery plane.

The authoritative path is:

`event → business context → objective/workflow → AI interpretation → capability resolution → policy/risk → Council/human approval → existing Action Kernel → durable outbox → governed connector → provider → result → reconciliation → business outcome → evidence/learning`

## Gates closed

### A — Event truth
V70.4 establishes a canonical event envelope requiring:
- workspace identity
- stable event identity
- event type/source
- correlation identity
- optional causation identity
- business payload

Existing V69 event-fabric and connector-event infrastructure remains the transport/durability implementation. This module does not replace it.

### B — Action truth
A canonical action identity is derived from:
- workspace
- workflow capability
- action type
- event identity

The resulting deterministic key is suitable for the existing durable idempotency boundary. It does not execute the action.

### C — Intelligence-to-execution truth
AI recommendations must resolve through the registered business capability catalog.

Possible states:
- `executable`: registered workflow + registered executable action
- `advisory_only`: known workflow, but its action is not currently registered for execution
- `capability_unavailable`: no registered workflow exists

No fuzzy matching or AI-generated workflow substitution is allowed.

### D — Business outcome truth
`OutcomeLink` makes the intended chain explicit:
`objective → workflow → action → outcome → evidence`.

Outcome measurement remains owned by the existing outcome/value-loop services.

## V70.3 reconciliation finding

The V70.3 customer-intelligence recommendations `sales.high-intent-follow-up` and
`sales.customer-engagement` are not present in the current catalog. V70.4 therefore
keeps them non-executable rather than inventing a workflow mapping.

## Certification status

V70.4 local reconciliation tests certify the contract and boundary logic. This is
not a live-provider certification. Real provider behavior, rate limits, credential
revocation, and production multi-worker behavior remain separate evidence gates.
