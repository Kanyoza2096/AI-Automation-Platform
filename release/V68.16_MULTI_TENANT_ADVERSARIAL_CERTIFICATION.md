# KDO V68.16 — Adversarial Multi-Tenant End-to-End Certification

## Purpose

V68.16 is a substantive adversarial certification phase for tenant isolation across the business operating chain. It tests two independent synthetic tenants through the same contracts and deliberately cross-wires tenant artifacts.

## Certified chain

`tenant boundary → business understanding → decision input → decision candidate → decision policy → synthetic execution truth → business outcome → attribution → learning → learning governance → decision context`

## Adversarial cases

1. Cross-tenant execution candidate cannot be attributed to the observing tenant.
2. Learning evidence cannot cite another tenant's source signal.
3. Promoted learning from another tenant cannot enter a tenant's decision context.
4. A knowledge ID from another tenant cannot be projected into a tenant's context.
5. Tenant A and tenant B lineage/knowledge identifiers remain disjoint.
6. Event ingress trusts the authenticated event-envelope workspace instead of a spoofed workspace embedded in the payload.

## Safety properties

- Certification uses a synthetic provider only.
- No real external API calls are made.
- No database writes are required by the harness.
- No authority, approval, policy, or execution permission is granted by certification.
- Cross-tenant violations fail closed at the tested boundaries.
- Production DB/RLS and Action Kernel enforcement remain authoritative; this test does not replace them.
