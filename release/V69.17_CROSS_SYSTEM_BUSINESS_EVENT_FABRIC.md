# V69.17 — Cross-System Business Event Fabric

V69.17 provides a tenant-scoped business event transport/fan-out plane for canonical events entering KDO from connectors and workflows.

## Safety boundary
The fabric stores, deduplicates, validates, sequences, and routes event envelopes. It does not call providers, connectors, HTTP endpoints, shells, or the Action Kernel, and cannot grant authority.

## Guarantees
- tenant-bound event and subscription storage
- duplicate event rejection and idempotent delivery uniqueness
- correlation and causation lineage
- sequence monotonicity per source
- hop/loop protection
- durable PostgreSQL event/subscription/delivery contract with RLS
- evidence emission for accepted/rejected publication
- delivery state is transport state, not execution authorization

## Tests
V69.17 focused tests cover routing, duplicates, tenant isolation, loop/hop protection, ordering and evidence.
