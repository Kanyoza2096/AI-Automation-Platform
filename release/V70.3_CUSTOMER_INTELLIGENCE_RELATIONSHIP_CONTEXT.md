# V70.3 — Customer Intelligence & Relationship Context

V70.3 adds a tenant-bound customer relationship intelligence/read model above the V70.2 sales loop.

## Boundary

Customer intelligence can aggregate identity, lifecycle context and business signals and produce an advisory next-workflow recommendation. It cannot grant authority, alter policy, call providers, invoke connectors, or execute actions.

## Flow

Customer observations → relationship context → advisory recommendation → existing V70.1 operating layer → existing governed automation path.

## Safety

- tenant isolation
- duplicate event fencing
- opt-out suppression
- deterministic fingerprints
- explicit advisory-only output
- no Action Kernel/provider/connector dependency

## Certification

Focused V70.3 tests plus the V69/V70 business-layer suites must pass before release.
