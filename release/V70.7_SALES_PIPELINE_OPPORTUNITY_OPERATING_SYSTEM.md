# KDO V70.7 — Sales Pipeline & Opportunity Operating System

V70.7 introduces a bounded opportunity state machine and pipeline projection above the existing governed automation runtime.

## Architecture
Business event → opportunity state validation → BusinessOperatingLayer → catalog workflow → Action Kernel → durable execution → CRM → lifecycle result.

The module performs no CRM/provider I/O and cannot grant authority.

## Stages
qualified → discovery → proposal → negotiation → won/lost.

Terminal states are immutable. Tenant and duplicate-event fences are enforced. Pipeline metrics expose open value, weighted pipeline, won/lost counts and won value.

## Persistence
Migration `082_v70_7_sales_pipeline_opportunity_operating_system.sql` creates the durable projection. The Python reference implementation remains intentionally side-effect free; production repository wiring should make this projection authoritative before certification.
