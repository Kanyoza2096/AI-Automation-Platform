# V71.16 — Canonical Autonomous Loop → Governed Workforce

## Purpose

Move the legacy AutonomousLoop from a potential local executor into a canonical
intelligence/proposal producer for the V71 Governed AI Workforce.

## Runtime law

`AutonomousLoop -> workforce proposal -> V71 identity/plan -> governance -> Action Kernel -> durable outbox -> connector/provider -> reconciliation`

The bridge itself never grants authority and never executes providers. If an
agent identity, plan, or workflow is not configured, the result is explicitly
`ADVISORY_ONLY` rather than an invented execution path.

## Legacy compatibility

The existing OODA/world-model/learning machinery remains. Existing event routing
remains available for observation and learning. Consequential `strategy_execute`
and autonomous `publish_request` handling no longer call the legacy action
pipeline directly; they are converted into workforce proposals.

## Certification boundary

Offline wiring and unit tests do not prove live provider execution, production
restart persistence, worker races, credential revocation, or provider rate-limit
behavior. Those remain live certification work.
