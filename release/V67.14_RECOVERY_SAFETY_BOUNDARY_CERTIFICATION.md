# V67.14 — Autonomous Recovery Safety Boundary Certification

## Purpose

V67.14 closes the boundary between autonomous recovery planning and external
side effects. Recovery is not an executor and cannot create a second execution
plane.

## Invariants certified by the focused suite

- Autonomous recovery is authority-free (`authority=none`).
- Only `AUTO_RECOVER + RETRY_EXISTING_INTENT` can be considered for autonomous release.
- Recovery must preserve the original intent ID, workspace, and action type.
- Recovery cannot manufacture, consume, or bypass human approval.
- Uncertain/partial execution remains reconciliation-first and cannot become a blind retry.
- Irreversible/high-impact recovery remains review-gated.
- Repeated transient failures exhaust a bounded retry budget and quarantine.
- Recovery has no direct provider/connector execution path and must re-enter `Action Outbox -> Action Kernel`.

## Scope

This is a control-plane certification. It does not constitute live third-party
provider certification. Actual provider behavior remains covered by the V67.10–V67.12
sandbox/reconciliation contracts and any future live staging certification.
