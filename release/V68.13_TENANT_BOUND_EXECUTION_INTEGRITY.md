- Reservation verifies the referenced rule exists.
- Reservation verifies the supplied workspace matches the rule workspace.
- Reservation verifies the supplied action matches the rule action.
- Added a database trigger enforcing workspace/action consistency for direct execution-ledger writes.
- Preserved the existing tenant-scoped idempotency fence and stale-reservation recovery behavior.
- No provider execution, approval, policy, or Action Kernel bypass introduced.
