# KDO V69.7 — Reference Connector Certification

## Purpose

V69.7 validates the V69.6 certification framework against an existing real connector implementation: Facebook Pages.

## What is certified

- Facebook connector identity and declared contract.
- Tenant-scoped integration connection.
- Opaque credential binding semantics.
- Explicit capability semantics: no native provider idempotency claim; authoritative post lookup is available.
- Ambiguous side-effect handling requires reconciliation rather than blind retry.
- Rate-limit handling is explicitly declared.
- Revocation/revalidation surface is declared.
- Mutations remain structurally behind `GovernedConnector`, `ExternalActionExecutor`, and the execution ledger.

## What is NOT certified

No Meta Graph API call is made by this test suite. Therefore this release does **not** claim live provider authentication, permission validity, API-version behavior, rate-limit response correctness, or successful remote mutation.

## Activation law

Offline certification is evidence for the connector contract. It does not grant a connection execution authority. Production activation still requires the V69 connection state progression, workspace policy, Decision Gate/Action Kernel authorization, durable execution, and reconciliation.

## Verification

Focused V69.7 tests must pass before a reference connector is considered structurally certified.
