# Phase 37.3 — Full Organism Integration

## Purpose

Phase 37.3 composes the organism primitives into one bounded cognitive lifecycle.
The runtime is intentionally an orchestration boundary, not a replacement for
existing authority systems.

## Lifecycle

`authoritative execution feedback -> learning -> perception -> state synthesis -> homeostasis + immune response -> prediction -> dreaming -> genome evaluation -> capability boundary -> cognitive governance`

Ecosystem signals enter through perception as low-trust external observations.

## Authority boundaries

- Durable execution records remain authoritative for external execution truth.
- Learning can create experience and derived world facts but cannot rewrite receipts.
- Prediction and dreaming are read-only reasoning layers.
- Genome evolution is declarative strategy configuration only.
- Capability checks are prerequisites, not execution authorization.
- Cognitive governance remains responsible for DecisionGate issuance.
- Guardian, credentials, connectors, and external execution remain outside the runtime.
- No cross-workspace observation, goal, feedback, strategy, or ecosystem signal is trusted without tenant validation.
- The async helper avoids nesting an event loop for FastAPI callers.

## Safety invariant

The integrated cycle may recommend, simulate, learn, and request governance. It
cannot acquire authority merely because another layer produced a favorable
prediction, dream, genome fitness score, or capability result.
