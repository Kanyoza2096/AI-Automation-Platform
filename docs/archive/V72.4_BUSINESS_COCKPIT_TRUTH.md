# V72.4 — Business Cockpit Durable Truth

V72.4 connects the Business Cockpit read model to existing authoritative V70/V71/V66 durable stores.

## Read sources
- Objectives: `business_operating_objectives`
- Opportunities: `sales_opportunity_operating_state`
- Risks / operations: `internal_business_work_state`
- Decisions: `decisions`
- Workforce: `agent_autonomous_runs`
- Outcomes: `business_outcome_observations`
- Evidence: `business_outcome_attributions`
- Governance evidence: `business_decision_audit`
- Runtime/business health: existing production runtime status

## Safety
This is a read-only projection. It never calls providers, Action Kernel, or execution code and every section explicitly returns `actionAuthorityGranted=false`.

Missing durable stores are represented as `UNKNOWN` / `UNAVAILABLE`; the cockpit never fabricates business facts.

## Boundary
The existing System Command Center remains `/api/v1/command-center/situation` and is not consumed by the Business Cockpit.
