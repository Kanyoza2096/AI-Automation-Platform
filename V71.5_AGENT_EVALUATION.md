# V71.5 — Governed AI Workforce: Agent Evaluation

V71.5 adds an evidence-based evaluation plane for measuring agent and plan performance.
Evaluation is deliberately separated from authority: scores, findings, averages and
performance summaries cannot grant permissions, approve plans, expand autonomy, or
invoke execution.

## Evaluated dimensions
- execution success
- business outcome alignment
- policy compliance
- runtime reliability
- recovery efficiency

Each dimension is optional until backed by observed evidence. Missing evidence produces
`INSUFFICIENT_EVIDENCE`, not a zero score and not an inferred success.

## Safety invariants
- evaluation never executes an action
- evaluation never grants authority or permissions
- evaluation never changes the autonomy envelope
- scores are advisory measurements only
- direct scores are bounded to 0..1
- count-derived scores reject invalid denominators and impossible counts
- plan and agent integrity are verified
- tenant boundaries are enforced
- evaluation records are fingerprinted and tamper-detectable
- performance summaries explicitly state `authority_granted=false`
